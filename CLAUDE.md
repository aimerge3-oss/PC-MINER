# CLAUDE.md — DROPZONE: CRYPTO RIGS (Промпты для coder.qwen.ai)

Telegram Mini App: коллекционирование и сборка комплектующих, сборка ПК и ASIC-майнеров, кейсы деталей, майнинг-ферма, мастерская, бенчмарки и дуэли майнеров.
Игровой дизайн и все цифры баланса — в [GDD.md](GDD.md). Состояние работы и следующие шаги — в [PROGRESS.md](PROGRESS.md).

## Как работать с ИИ-кодером (coder.qwen.ai)
- Общение на **русском**. Объяснять структуру и код понятно и структурировано.
- **Перед каждой новой фичей задавать уточняющие вопросы** по логике и верстке.
- После каждого изменения проверять код на стабильность, отсутствие синтаксических ошибок и связность модулей.
- При каждом изменении интерфейса увеличивать версию `?v=N` у всех `css`/возникающих скриптов в `index.html` для предотвращения кэширования в Telegram.

## Стек и запуск
- Чистые HTML/CSS/JS, без сборки и тяжелых фреймворков. Скрипты подключаются через обычные `<script>` (глобальные переменные и модули через `globalThis`).
- Локальный запуск: `python -m http.server 5173` -> открыть `http://localhost:5173`.
- Хостинг: GitHub Pages / Telegram WebApp.

## Архитектура клиента (порядок подключения в index.html)
| Файл | Назначение |
|---|---|
| `js/data.js` | Все данные и баланс: комплектующие (процессоры, видеокарты, материнские платы, ОЗУ, SSD, блоки питания, кулеры), ASIC-майнеры, готовые сборки ПК, кейсы, награды, уровни. |
| `js/rules.js` | **Общие правила и логика** (IIFE -> `globalThis.Rules`): справочники, расчеты хэшрейта, энергопотребления, стоимости, доходов, а также все действия игрока (`Rules.actions`). |
| `js/rewards.js` | Награды: ежедневный бонус, кейс наград, коллекция железа, слоты в мастерской/стойках. |
| `js/workshop.js` | Управление мастерской, установка деталей в ПК и ASIC, склад комплектующих, слияние деталей. |
| `js/game.js` | Главный файл инициализации, состояние интерфейса, вкладки, магазин кейсов, шторки (bottom sheets). |

## Структура папок ассетов
- `img/pc/` — превью готовых ПК (со студийным фоном).
- `img/asics/` — изображения ASIC-майнеров.
- `img/gpus/` — видеокарты.
- `img/cpus/` — процессоры.
- `img/motherboards/` — материнские платы.
- `img/cooling/` — системы охлаждения.
- `img/ram/` — оперативная память.
- `img/storage/` — накопители (SSD/HDD).
- `img/psu/` — блоки питания.
